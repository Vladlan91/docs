Mit Revol MCP arbeiten Sie direkt in ChatGPT, Claude oder Gemini CLI mit Unternehmensdaten. Der Assistent kann Daten lesen und die für Sie verfügbaren Aktionen für Gespräche, Leads, Produkte, KI-Agenten und Analysen ausführen.

## Vor dem Verbinden

- Melden Sie sich bei Revol an und prüfen Sie Ihren Zugriff auf das gewünschte Unternehmen.
- Das Abonnement des Unternehmens muss den Zugriff auf das MCP-Modul ermöglichen.
- Ihr ChatGPT-/Claude-Konto oder Arbeitsbereich muss eigene MCP-Konnektoren zulassen. Fehlt die Option, prüfen Sie die Zugriffsregeln mit Ihrem Administrator.

## Verbindungseinstellungen

| Feld | Wert |
|---|---|
| Name | `Revol` |
| Server-URL / Connection | `https://revol-ai.app/mcp` |
| Authentication | **OAuth** |
| OAuth-Clientregistrierung, falls auswählbar | Automatisch / **DCR** |
| Client ID und Client Secret | Für die automatische Registrierung leer lassen |
| Transport, falls auswählbar | **Streamable HTTP** |

<Note>
  Revol verlangt bereits beim Verbindungsaufbau eine Authentifizierung. Wählen Sie in ChatGPT **OAuth**: **No authentication** führt zu **The MCP server denied access**.
</Note>

## ChatGPT

1. Öffnen Sie **Add custom MCP server** im Bereich für Apps, Konnektoren oder Plugins Ihrer Oberfläche.
2. Übernehmen Sie die Einstellungen aus der Tabelle und wählen Sie **OAuth**. Client ID und Client Secret müssen nicht manuell eingetragen werden.
3. Bestätigen Sie die Einrichtung. Melden Sie sich auf der Revol-Seite an und erteilen Sie den Zugriff wie unten beschrieben.
4. Kehren Sie zu ChatGPT zurück und schließen Sie die Plugin-Installation ab. Öffnen Sie einen neuen Chat, wählen Sie **@Revol** in der Nachricht und bitten Sie um einen reinen Leseaufruf von `revol_whoami`.

Für das Symbolfeld können Sie das [Revol-Logo als PNG](https://revol-ai.app/favicon.png) herunterladen: **256 × 256 px, 2,7 KB**. Die Datei liegt unter dem Formularlimit von 10 KB.

Die aktuellen Menüpfade finden Sie in der [OpenAI-Anleitung](https://developers.openai.com/api/docs/guides/custom-mcp-server).

## Claude

Fügen Sie unter **Connectors** einen eigenen Konnektor mit den obigen Einstellungen hinzu. Falls angeboten, wählen Sie **Sign in now** und beim OAuth-Client **Register automatically**. Erteilen Sie den Zugriff in Revol und aktivieren Sie den Konnektor im Chat.

Menüpfade und Administratorrechte: [Claude-Anleitung](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

## Gemini CLI

Fügen Sie in einer installierten Gemini CLI denselben Streamable-HTTP-Endpunkt hinzu:

```bash
gemini mcp add --transport http Revol https://revol-ai.app/mcp
```

Starten Sie Gemini CLI und führen Sie `/mcp auth Revol` aus, um OAuth im Browser abzuschließen. Prüfen Sie die Verbindung mit `/mcp`. Automatische Erkennung und Client-Registrierung nutzen denselben Revol-Autorisierungsablauf wie andere Clients.

Diese Schritte gelten für **Gemini CLI**. Die Gemini-Website und andere Google-Produkte haben eigene Integrationsmöglichkeiten; das Hinzufügen in der CLI aktiviert den Server dort nicht.

[Gemini-CLI-Dokumentation](https://geminicli.com/docs/tools/mcp-server/).

## Zugriff in Revol erteilen

Auf dem Zustimmungsbildschirm:

1. Wählen Sie ein oder mehrere Unternehmen für den Assistenten aus. Lange Listen lassen sich innerhalb des Formulars scrollen.
2. Wählen Sie das passende Toolset für Ihre Aufgabe.
3. Klicken Sie auf **Erlauben**, um zu ChatGPT, Claude oder Gemini CLI zurückzukehren.

| Toolset | Zweck |
|---|---|
| **Gespräche & Vertrieb** | Gespräche, Teamarbeit, Leads, Produkte und Abteilungsskripte |
| **KI-Agenten-Verwaltung** | Agenten, Workflows, Wissensdatenbank, Dateien, Kanäle und Unternehmenseinstellungen |
| **Analytik, Abrechnung & Tracking** | KPIs, Metriken, Abrechnung, Diagnose und Website-Tracking |
| **Vollzugriff** | Alle Tools, die Ihre Berechtigungen und Ihr Abonnement zulassen |

Das Profil begrenzt die Tools, erweitert aber nicht Ihre Rolle. Der Assistent handelt als die Person, die die Verbindung autorisiert hat; Einschränkungen für Unternehmen, Arbeitsbereich und Abonnement gelten weiterhin. „Vollzugriff“ erteilt keine Administratorrechte.

## Verbindung prüfen

Bitten Sie den Assistenten:

> Zeige über Revol die Unternehmen, die dieser Verbindung zur Verfügung stehen.

Wenn Sie mehrere Unternehmen ausgewählt haben, nennen Sie das gewünschte Unternehmen bei jeder Aufgabe, etwa: „Zeige über Revol die Produktliste des Unternehmens ‹Beispiel›.“ Jede Aktion muss im Kontext eines einzelnen Unternehmens erfolgen.

## Zugriff verwalten und widerrufen

Öffnen Sie das entsprechende Unternehmen in Revol und gehen Sie zu **Mein Assistent**. In der Verbindungskarte können Sie einzelne Tools deaktivieren oder auf **Trennen** klicken. Die Verbindung kann von ihrem Ersteller oder einem Eigentümer eines darin enthaltenen Unternehmens verwaltet werden.

Das Trennen widerruft die gesamte Verbindung einschließlich aller dafür ausgewählten Unternehmen. Für eine andere Unternehmensauswahl oder ein anderes Profil durchlaufen Sie OAuth erneut. Zeigt der Client noch eine alte Toolliste an, aktualisieren Sie diese oder beginnen Sie einen neuen Chat.

## Tools sind in Revol aktiviert, fehlen aber im Chat

Die Schalter in **Mein Assistent** bestimmen, was Revol dieser Verbindung erlaubt. Der Client muss außerdem den Toolkatalog laden und das Plugin für die Nachricht aktivieren.

Öffnen Sie in ChatGPT die Verbindung und wählen Sie **Refresh** oder aktualisieren Sie die Aktionen in den App-Einstellungen des Arbeitsbereichs. Prüfen Sie die erkannten Tools und deren Berechtigungen. Öffnen Sie dann einen neuen Chat mit **@Revol** und testen Sie `revol_whoami`. Manche Tarife, Modi oder Arbeitsbereichsrichtlinien erlauben nur Lesezugriffe. Siehe [OpenAI-Verbindungs- und Aktionskontrollen](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt).

Falls ein großer Katalog die Erkennung in einem MCP-Client erschwert, verbinden Sie sich erneut mit dem passenden Toolprofil. Eine erfolgreiche OAuth-Seite oder die Antwort „verbunden“ ersetzt keinen erfolgreichen Toolaufruf.

Die App-Karte — Beschreibung, Kategorie, Entwickler, Website und Logo — wird vom Client verwaltet. Gespeicherte Felder können von Servermetadaten abweichen; eine Bearbeitung der Karte behebt keine Toolerkennungsfehler.

## Häufige Probleme

| Symptom | Prüfung |
|---|---|
| **The MCP server denied access** direkt beim Hinzufügen | Stellen Sie **Authentication → OAuth** ein und verbinden Sie erneut mit `https://revol-ai.app/mcp` |
| `401` oder `Missing bearer token` beim Öffnen der URL im Browser | Die URL ist keine Anmeldeseite. Fügen Sie sie im MCP-Client hinzu und durchlaufen Sie OAuth |
| Ein Unternehmen fehlt auf dem Zustimmungsbildschirm | Prüfen Sie das verwendete Revol-Konto und dessen Unternehmenszugriff |
| Verbunden, aber keine Tools verfügbar oder Aktion verweigert | Prüfen Sie Unternehmensabonnement, Rolle, Profil und deaktivierte Tools unter **Mein Assistent** |
| Der Assistent weiß nicht, welches Unternehmen gemeint ist | Nennen Sie ein beim Verbinden freigegebenes Unternehmen |
| Nach dem Widerruf funktioniert die Verbindung nicht mehr | Autorisieren Sie Revol erneut über OAuth |
| Standardsymbol statt Revol-Logo | Laden Sie das PNG-Logo im Symbolfeld des Konnektors hoch |
