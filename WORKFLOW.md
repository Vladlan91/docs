# Робота з публічною документацією

Навігація та мови визначені в [docs.json](docs.json): en, uk, pl, de, es.
Працюй із потрібною локаллю й узгоджуй залежні переклади. Обговорення з власником —
українською; дозвіл на публікацію визначає поточне доручення.

Перед зміною звір поведінку з core-кодом, чинним контрактом та відкритими питаннями.
Нові сторінки додавай до навігації; не дублюй неперевірені обіцянки зі старих планів.
MDX — вміст сайту, тому відсутність згадки в README не означає, що сторінка зайва.

Використовуй наявні Mintlify-компоненти за прикладами сусідніх сторінок:
`CardGroup`/`Card`, `Tabs`/`Tab`, `Steps`/`Step`, `AccordionGroup`/`Accordion`,
`Note`/`Tip`/`Warning`, `CodeGroup`, `Frame`. Зображення — в `images/`, з описовою
назвою й alt; не залишай посилань на відсутні скриншоти як готовий результат.

Перевір локальні посилання, assets, навігацію та MDX у доступному preview;
`git diff --check` не замінює рендер. У коміт входять лише зміни доручення,
сторонні редагування й видалення зберігаються.

## Тарифи та скриншоти білінгу

Джерело каталогу — `billing_plans`, модель `Plan`, billing-міграції й
`resources/lang/*/billing.php` core. Звіряй ціни, квоти та окремо доступність
самостійного підключення. Для обліку ресурсів джерело —
`GetAccountUsageAction` і `BillingPeriodService`; для доступу — `AccessGrant`.
Публічні умови живуть у `*/billing/plans.mdx`, пояснення використання — у
`*/billing/usage.mdx`. Розділ білінгу в `concepts.mdx` посилається на них.
Оновлюй п’ять мов і старі англійські маршрути `billing/` разом; ціни й
можливості також узгоджуй із `/pricing` та прикладом чату в `landing/`.

`images/billing-catalog-{light,dark}.png` та
`images/billing-access-{light,dark}.png` — англійські знімки чинних Blade-шаблонів
`billing/pricing`, `billing/access` і `billing/partials/account-usage` core.
Для кадрів без приватних даних відрендери сам вміст шаблонів із перевіреним
read-only каталогом і синтетичними значеннями usage, без запису в БД.
Компіляцію Blade й тимчасові файли тримай поза checkout. Використовуй справжні
CSS/шрифти core та `body[data-pc-theme="light|dark"]`; сервер має віддавати
HTML і шрифти з одного origin, інакше CORS може залишити квадрати замість іконок.
Знімай при ширині 1600 px після завантаження шрифтів; usage-кадр охоплює
статус і картки ресурсів, без заглушки журналу подій. Дані прикладу позначай
як демонстраційні. Копії каталогу в `landing/public/` мають збігатися.

Локальний preview запускається через `mint dev`; CLI потребує Node >=20.17.
На старішому локальному Node можна використати ізольований запуск
`npx --yes --package=node@22 --package=mint mint dev --port 4195 --no-open`.
Перевір MDX, локальні посилання, усі мови та обидві теми зображень у браузері.
