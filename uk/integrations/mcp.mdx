Revol MCP дозволяє працювати з даними компанії безпосередньо в ChatGPT, Claude або Gemini CLI. Асистент може читати дані й виконувати доступні вам операції з розмовами, лідами, продуктами, AI-агентами та аналітикою.

## Перед підключенням

- Увійдіть у свій акаунт Revol і перевірте доступ до потрібної компанії.
- Для компанії має бути доступний модуль MCP за її підпискою.
- Ваш акаунт або робочий простір ChatGPT/Claude має дозволяти додавання власних MCP-конекторів. Якщо відповідного пункту немає, перевірте налаштування доступу з адміністратором.

## Параметри підключення

| Поле | Значення |
|---|---|
| Назва | `Revol` |
| URL сервера / Connection | `https://revol-ai.app/mcp` |
| Authentication | **OAuth** |
| Реєстрація OAuth-клієнта, якщо є вибір | Автоматична / **DCR** |
| Client ID і Client Secret | Залиште порожніми для автоматичної реєстрації |
| Транспорт, якщо є вибір | **Streamable HTTP** |

<Note>
  Revol потребує авторизації вже під час підключення. У ChatGPT оберіть **OAuth**: режим **No authentication** призводить до помилки **The MCP server denied access**.
</Note>

## ChatGPT

1. Відкрийте додавання власного MCP-сервера: **Add custom MCP server** у розділі застосунків, конекторів або плагінів вашого інтерфейсу.
2. Заповніть поля за таблицею вище, обов'язково вибравши **OAuth**. Ручні Client ID та Client Secret не потрібні.
3. Підтвердьте створення підключення. На сторінці Revol увійдіть у свій акаунт і надайте доступ за інструкцією нижче.
4. Поверніться до ChatGPT й завершіть установлення плагіна. Відкрийте новий чат, оберіть **@Revol** у повідомленні та попросіть викликати `revol_whoami` лише для читання.

Для поля іконки завантажте [PNG-логотип Revol](https://revol-ai.app/favicon.png): **256 × 256 px, 2,7 КБ**. Він відповідає обмеженню форми до 10 КБ.

Актуальне розташування пунктів меню: [інструкція OpenAI](https://developers.openai.com/api/docs/guides/custom-mcp-server).

## Claude

У розділі **Connectors** додайте власний конектор за параметрами вище. Якщо Claude пропонує спосіб входу, оберіть **Sign in now**, а для OAuth-клієнта — **Register automatically**. Пройдіть надання доступу в Revol і ввімкніть конектор у чаті.

Розташування розділу й права адміністратора: [інструкція Claude](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

## Gemini CLI

У встановленому Gemini CLI додайте той самий endpoint Streamable HTTP:

```bash
gemini mcp add --transport http Revol https://revol-ai.app/mcp
```

Запустіть Gemini CLI та виконайте `/mcp auth Revol`, щоб пройти OAuth у браузері. Перевірте підключення командою `/mcp`. Автоматичне виявлення налаштувань і реєстрація клієнта використовують той самий процес авторизації Revol.

Ці кроки стосуються **Gemini CLI**. Сайт Gemini та інші продукти Google мають власні можливості інтеграції; додавання сервера в CLI не вмикає його там.

[Документація Gemini CLI](https://geminicli.com/docs/tools/mcp-server/).

## Надання доступу в Revol

На екрані згоди:

1. Позначте одну або кілька компаній, із якими працюватиме асистент. Довгий список прокручується всередині форми.
2. Оберіть набір інструментів під свою задачу.
3. Натисніть **Дозволити**, щоб повернутися до ChatGPT, Claude або Gemini CLI.

| Набір інструментів | Для чого |
|---|---|
| **Розмови й продажі** | Переписки, командна робота, ліди, продукти та скрипти відділів |
| **Адміністрування AI-агентів** | Агенти, workflow, база знань, файли, канали й налаштування компанії |
| **Аналітика, білінг і трекінг** | KPI, метрики, білінг, діагностика та трекінг сайту |
| **Повний доступ** | Усі інструменти, доступні в межах ваших прав і підписки |

Профіль обмежує набір інструментів, але не розширює вашу роль. Асистент діє від імені того, хто авторизував підключення; обмеження компанії, робочого простору та підписки зберігаються. «Повний доступ» не надає прав адміністратора.

## Перевірка підключення

Попросіть асистента:

> Через Revol покажи компанії, доступні цьому підключенню.

Якщо обрано кілька компаній, указуйте назву потрібної в кожній задачі, наприклад: «У компанії “Приклад” через Revol покажи список продуктів». Асистент має виконувати кожну операцію в контексті однієї компанії.

## Керування та відкликання

Відкрийте потрібну компанію в Revol і перейдіть у **Мій Асистент**. У картці підключення можна вимкнути окремі інструменти або натиснути **Відключити**. Керувати підключенням може його автор або власник компанії, що входить до нього.

Відключення відкликає все підключення, включно з усіма обраними для нього компаніями. Для нового набору компаній або іншого профілю пройдіть OAuth повторно. Якщо клієнт показує старий список інструментів, оновіть його або почніть новий чат.

## У Revol інструменти ввімкнені, але в чаті їх немає

Перемикачі в **Мій Асистент** визначають, що Revol дозволяє цьому підключенню. Клієнт також має завантажити каталог інструментів і ввімкнути плагін для повідомлення.

У ChatGPT відкрийте підключення й натисніть **Refresh** або оновіть дії в налаштуваннях застосунків робочого простору. Перевірте знайдені інструменти та дозволи на них, потім відкрийте новий чат із **@Revol**. Для перевірки використайте `revol_whoami`. Деякі плани, режими чи політики робочого простору дозволяють лише читання. Див. [налаштування підключень і дій OpenAI](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt).

У будь-якому MCP-клієнті, якщо великий каталог заважає завантаженню, повторіть підключення з профілем інструментів для потрібної задачі. Успішний екран OAuth або відповідь асистента «підключено» не замінюють успішного виклику інструмента.

Карткою застосунку — описом, категорією, розробником, сайтом і логотипом — керує клієнт. Збережені поля можуть відрізнятися від метаданих сервера; редагування картки не виправляє завантаження інструментів.

## Типові проблеми

| Симптом | Що перевірити |
|---|---|
| **The MCP server denied access** одразу при додаванні | Установіть **Authentication → OAuth** і повторіть підключення з URL `https://revol-ai.app/mcp` |
| `401` або `Missing bearer token` при відкритті URL у браузері | Сам URL не є сторінкою входу. Додайте його в MCP-клієнті й пройдіть OAuth |
| На екрані згоди немає потрібної компанії | Перевірте, під яким акаунтом Revol ви ввійшли та чи має він доступ до компанії |
| Підключення є, але немає інструментів або операція заборонена | Перевірте підписку компанії, вашу роль, профіль і вимкнені інструменти в **Мій Асистент** |
| Асистент не знає, яку компанію використати | Укажіть потрібну компанію із дозволених під час підключення |
| Підключення перестало працювати після відкликання | Авторизуйте Revol заново через OAuth |
| Замість логотипа Revol стандартна іконка | Завантажте PNG-логотип у поле іконки конектора |
